# Macast 录制插件

一款用于Macast的DLNA流媒体录制插件，使用FFmpeg在播放媒体的同时将流录制为MP4文件。

## 功能特性

- **自动录制**：当媒体投屏到Macast时自动开始录制
- **手动控制**：通过系统托盘菜单手动开始或停止录制
- **高质量输出**：H.264视频（6000 kbps）+ AAC音频（192 kbps）
- **实时状态**：在菜单中显示录制时长和文件大小
- **自定义保存路径**：通过原生文件对话框选择录制文件的保存位置
- **自定义FFmpeg路径**：配置自定义FFmpeg可执行文件位置或使用自动检测
- **智能文件命名**：文件以媒体标题和时间戳命名（如 `视频标题_20260515_143025.mp4`）
- **优雅停止**：向FFmpeg发送 `q` 命令进行干净收尾，备选SIGINT/terminate信号
- **FFmpeg验证**：每次录制前验证FFmpeg可用性和版本信息
- **启动验证**：检测FFmpeg启动后是否立即退出并报告错误
- **无效输出检测**：自动删除小于1 KB的输出文件
- **FFmpeg日志捕获**：将FFmpeg的stderr输出捕获到日志文件中，便于故障排查
- **跨平台**：支持macOS、Windows和Linux

## 系统要求

- Macast 0.7或更高版本
- FFmpeg（项目内置、自定义路径或系统PATH）

## 安装方法

### 手动安装

1. 将 `recorder` 文件夹复制到Macast的renderer目录：
   - **Windows**: `%APPDATA%\xfangfang\Macast\renderer\`
   - **macOS**: `~/.config/Macast/renderer/`
   - **Linux**: `~/.config/Macast/renderer/`

2. 重启Macast

3. 在渲染器菜单中选择 **Recording Renderer**

## 使用说明

### 自动录制

默认情况下，投屏时会自动开始录制：

1. 在Macast中选择 **Recording Renderer** 作为渲染器
2. 从手机或设备投屏媒体
3. 录制自动开始
4. 停止投屏或选择 **停止投屏** 结束录制
5. 通知将显示录制的时长和文件大小

### 手动录制

1. 右键点击系统托盘或菜单栏中的Macast图标
2. 进入 **设置** > **Recording Renderer** 菜单
3. 点击 **开始录制** 启动录制
4. 点击 **停止录制** 结束录制

> **注意**：手动录制需要有活跃的媒体流。如果当前没有正在播放的媒体，将显示错误通知。

## 配置说明

所有设置均可通过Macast系统托盘菜单中的 **Recording Renderer** 子菜单访问。

### 菜单选项

```
录制: 空闲                            （状态显示，只读）
────────────────────────────────────────
开始录制                              （手动开始）
停止录制                              （手动停止，空闲时禁用）
────────────────────────────────────────
投屏时自动录制                [✓]      （切换投屏时自动录制）
保存路径: .../Videos/Macast           （点击更改保存位置）
FFmpeg路径: 自动检测                  （点击设置自定义FFmpeg路径）
```

### 投屏时自动录制

启用时（默认），投屏到Macast的媒体会自动开始录制。切换此选项可禁用自动录制，仅使用手动控制。

### 保存路径

点击打开文件夹选择对话框，更改录制文件的保存位置。默认保存路径为用户主目录。

- **macOS**：通过AppleScript使用原生文件夹选择器
- **Windows**：使用tkinter文件夹对话框
- **Linux**：使用tkinter文件夹对话框

### FFmpeg路径

点击设置自定义FFmpeg可执行文件路径。支持文件路径和目录路径：

- **文件路径**：FFmpeg可执行文件的直接路径（如 `D:\devsoft\ffmpeg\ffmpeg.exe`）
- **目录路径**：包含FFmpeg的目录（如 `D:\devsoft\ffmpeg`），插件会自动在该目录中查找 `ffmpeg.exe`（Windows）或 `ffmpeg`（macOS/Linux）
- **自动检测**：留空使用自动检测（默认）

自动检测时的FFmpeg查找优先级：

1. 用户配置的自定义路径（如已设置）
2. 项目目录中内置的FFmpeg
3. 系统PATH环境变量
4. 默认命令名 `ffmpeg`

## 录制状态

菜单中显示实时录制状态：

- **录制: 空闲** — 无活动录制
- **录制: 00:05:23 - 156.3 MB** — 正在录制中（时长和文件大小实时更新）

## 输出格式

| 设置 | 值 |
|------|-----|
| 容器 | MP4（MPEG-4） |
| 视频编码 | H.264（libx264） |
| 视频比特率 | 6000 kbps（可配置） |
| 视频预设 | fast |
| 像素格式 | yuv420p |
| 音频编码 | AAC |
| 音频比特率 | 192 kbps（可配置） |
| 快速启动 | 已启用（`+faststart` movflag） |

> 输出保持源分辨率、帧率、采样率和声道布局不变。

## 文件命名

文件以录制开始时间和可选的媒体标题命名：

- **无标题**：`YYYYMMDD_HHMMSS.mp4`（如 `20260515_143025.mp4`）
- **有标题**：`标题_YYYYMMDD_HHMMSS.mp4`（如 `我的视频_20260515_143025.mp4`）

标题中的特殊字符会被自动清理（仅保留字母数字、空格、连字符和下划线）。

## FFmpeg日志文件

每次录制会在保存目录中生成一个隐藏的FFmpeg日志文件：

- **命名规则**：`.{文件名}.ffmpeg.log`（如 `.20260515_143025.mp4.ffmpeg.log`）
- **内容**：捕获FFmpeg的stderr输出（进度、警告、错误）
- **编码**：以二进制模式写入，确保跨平台兼容性
- **用途**：录制失败时用于错误诊断

## 配置键名

插件将设置存储在Macast的配置文件中，这些键名可在高级设置JSON中找到：

| 键名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `Record_SavePath` | string | 用户主目录 | 录制文件的保存目录 |
| `Record_AutoStart` | int | `1` | 投屏时自动录制（1 = 启用，0 = 禁用） |
| `Record_VideoBitrate` | string | `6000k` | FFmpeg输出的视频比特率 |
| `Record_AudioBitrate` | string | `192k` | FFmpeg输出的音频比特率 |
| `Record_FFmpegPath` | string | `""` | 自定义FFmpeg路径（空 = 自动检测） |

## 故障排除

### "录制失败 — 无法开始录制，请检查FFmpeg安装及日志文件。"

此错误表示无法找到FFmpeg或FFmpeg启动失败。请检查以下内容：

1. **验证FFmpeg已安装**：
   ```bash
   ffmpeg -version
   ```

2. **在插件设置中配置FFmpeg路径**：点击菜单中的 **FFmpeg路径**，选择FFmpeg可执行文件或其所在目录。

3. **查看Macast日志**获取详细错误信息。

4. **检查FFmpeg日志文件**：在保存目录中查找名为 `.*.ffmpeg.log` 的文件。

### "当前没有正在播放的媒体"

此提示出现在没有活跃媒体流时手动启动录制。请确保在点击 **开始录制** 之前已有媒体投屏到Macast。

### 录制无法启动 / 无输出文件生成

1. 验证FFmpeg可用且可执行
2. 检查保存路径是否存在且可写
3. 在保存目录中查找FFmpeg日志文件（`.ffmpeg.log`）获取错误详情
4. 如果日志文件为空，可能是FFmpeg未能启动——请验证FFmpeg二进制文件与您的平台兼容

### FFmpeg日志文件为空

日志文件为空通常表示：

- FFmpeg二进制文件与当前平台不兼容
- FFmpeg在写入任何输出前即崩溃
- 文件权限阻止FFmpeg运行

### 录制文件损坏或文件过小

1. 检查可用磁盘空间
2. 验证源媒体流URL可从您的计算机访问
3. 插件会自动删除小于1 KB的输出文件，因为它们通常表示录制失败
4. 查看FFmpeg日志文件中的流访问错误

### 自定义FFmpeg路径不生效

- 如果设置的是 **目录路径**，请确保该目录中存在 `ffmpeg.exe`（Windows）或 `ffmpeg`（macOS/Linux）
- 如果设置的是 **文件路径**，请确保该文件具有可执行权限
- 查看Macast日志中是否有"自定义FFmpeg路径存在但不可执行"等提示信息

## 日志文件

Macast应用日志存储位置：

- **Windows**: `%APPDATA%\xfangfang\Macast\macast.log`
- **macOS**: `~/.config/Macast/macast.log`
- **Linux**: `~/.config/Macast/macast.log`

FFmpeg录制日志以隐藏文件形式存储在保存目录中（`.文件名.ffmpeg.log`）。
